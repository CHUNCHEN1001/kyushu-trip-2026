## 上傳與啟用

1. 進入 [Settings → Pages](https://github.com/CHUNCHEN1001/kyushu-trip-2026/settings/pages)。
2. Source 選 Deploy from a branch；Branch 選 main，資料夾選 /(root)，按 Save。
3. 等待發布完成，再按 Visit site 開啟。首次發布可能需數分鐘。

這是單一 HTML 網頁，沒有外部套件或建置步驟；本機也可以直接開啟 `index.html`。
